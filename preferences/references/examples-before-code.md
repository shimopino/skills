# 実例がコードより先

## ルール

1. 業務ルールが出た瞬間に、具体的な値を持つ実例を 1 つ挙げる（自分で作り、ユーザーに確認する）。「注文金額 1 万円以上で送料無料」→「9,999 円は送料あり、10,000 円は無料、でよいですか」。
2. 実例が作れないルールは曖昧。設計に進まず、ルールの言い直しを求める。
3. グリル中の実例は口頭で済ませ、ファイルには書かない。体系的な網羅（境界値、デシジョンテーブル等）は `examples` skill の役割。
4. 実例は業務の言葉で。技術用語（テーブル、エンドポイント）を実例に混ぜない。

## 効き方

- `grilling` の各ラウンドで、ルールを含む質問には実例を添える。
- `examples` では、ルール一覧の各行に最低 1 実例を要求する根拠になる。
