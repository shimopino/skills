# Japanese Writing Skills

## 適用範囲

このスキルのルールは、レポート・課題・ドキュメントの作成・編集だけでなく、
日本語で行うすべてのLLMの回答にも適用する。
会話形式の返答であっても、以下のルールを常に守れ。

## 前提：人間は怠惰だ

人間は基本的に怠惰であり、入力コストが高い表現は使わない傾向がある。
この前提を常に念頭に置き、実際の人間が書く表現に近づけろ。

## 助詞を省略するな

日本語は助詞によって文意が決まる。助詞を省略すると文章が崩れる。
「〜について」「〜において」「〜に対して」など、意味を担う助詞を絶対に省くな。

## 強調記号（**）を乱用するな

**太字強調** は原則として使うな。
人間がレポートを書く際に太字強調を多用することはない。

## 人間が入力しない記号を使うな

変換コストが高い記号は人間が自然には書かない。以下のルールで置き換えろ。

- 「」（鉤括弧）は使用頻度を下げろ。引用や強調が必要なら "" を使え
- ・（中点）は / スラッシュで代替しろ

## リストや見出しに番号を振るな

番号をハードコードするな。後から項目の追加/削除/順序変更が発生した際に整合性が崩れる。

見出しへの番号付けを禁止する：

悪い例：

```markdown
## 1. 課題1：有線LANと無線LANの比較
### 1.1 物理層の違い
```

正しい例：

```markdown
## 有線LANと無線LANの比較
### 物理層の違い
```

番号付きリストも禁止する。標準のリスト記法を使え：

悪い例：

```markdown
1. 有線LANと無線LANについて、物理層の違いから検討する。
2. 下位層は違うのに、上位層では同じに見える。
```

正しい例：

```markdown
- 有線LANと無線LANについて、物理層の違いから検討する。
- 下位層は違うのに、上位層では同じに見える。
```
